# クオンツトレード基礎：確率過程からエッジまで

クオンツトレードとは、データ・統計・数理モデルを用いて、**再現可能なルールと期待値の根拠**を持って市場に参加する手法。裁量トレードとの最大の違いは、「次に上がるか下がるか」ではなく「**どのくらいの幅で揺れるか、どの程度の損失が起こり得るか**」を問う点にある。

> 確率過程は予測の魔法ではなく、金融市場の不確実性を扱うための土台。

---

## 1. クオンツ的思考への転換

| 裁量的な見方 | クオンツ的な見方 |
|---|---|
| 価格は一本の線として予測できる | 未来の価格は確率的な広がり（分布）として存在する |
| 高勝率＝良い戦略 | 損益比率とドローダウンが重要 |
| バックテスト勝利＝本番勝利 | 過学習の検出とアウトオブサンプル検証が必須 |
| 高ボラ＝チャンス | スプレッド拡大とノイズ増加の側面もある |
| チャート形状で判断可能 | 統計的検証なしに形状は根拠にならない |

中心的な問いは「**期待値がプラスになる条件が存在するか**」であり、個別の予測精度ではない。

## 2. 確率過程の基礎

### 2.1 定義

時間とともに変化するランダムな値の列を**確率過程**（Stochastic Process）と呼ぶ。

$$\{X_t\}_{t \geq 0}$$

金融価格は決定論的ではなく、各時刻において確率的な分布を持つ時系列として扱う。

### 2.2 マルコフ性

**マルコフ性**：次の状態が現在の状態にのみ依存し、過去の履歴に依存しない性質。

$$P(X_{t+1} \mid X_t, X_{t-1}, \ldots) = P(X_{t+1} \mid X_t)$$

日次終値の価格変化は近似的にマルコフ的に扱われることが多い（完全ではない）。

### 2.3 定常性

**弱定常性**（Weak Stationarity）：平均・分散・自己共分散が時間に依存しない。

$$E[X_t] = \mu \quad \text{(定数)}$$
$$\text{Cov}(X_t, X_{t+k}) = \gamma(k) \quad \text{（時刻に依存しない）}$$

- 価格そのものは非定常になりやすい（単位根を持つ）
- **対数リターン**は価格より定常的に扱いやすく、モデル化に適している

## 3. ランダムウォークと対数リターン

### 3.1 ランダムウォーク

最も基本的な価格モデル：

$$X_{t+1} = X_t + \varepsilon_{t+1}, \quad \varepsilon_t \overset{\text{i.i.d.}}{\sim} (0, \sigma^2)$$

**ホワイトノイズ** $\varepsilon_t$ の性質：
- 平均が 0
- 分散が一定
- 時点間の自己相関がない

ノイズの階層関係：

$$\text{正規i.i.d.ノイズ} \subset \text{i.i.d.ノイズ} \subset \text{ホワイトノイズ}$$

ランダムウォークに対する検定として**ADF検定**（Augmented Dickey-Fuller Test）や**KPSS検定**がある。両者は帰無仮説が逆向きである点に注意：ADF は「単位根あり（非定常）」が帰無仮説、KPSS は「定常」が帰無仮説。ADF で単位根を棄却できないことは「非定常の証明」ではなく「定常性の証拠が不十分」を意味するため、両検定を併用して判断するのが実務的。

### 3.2 対数リターン

$$r_t = \log P_t - \log P_{t-1} = \log \frac{P_t}{P_{t-1}}$$

採用理由：

| 特性 | 内容 |
|---|---|
| 非定常性の除去 | 価格水準の影響を取り除く |
| 加法性 | $r_{1 \to 3} = r_1 + r_2 + r_3$（複数期間を単純加算できる） |
| 幾何ブラウン運動との整合性 | 連続時間モデルと相性が良い |
| 対称性 | 「倍になる」(+100%)と「半分になる」(−50%)が $\pm\log 2$ と等しい絶対値の対数リターンに対応する |

## 4. 幾何ブラウン運動（GBM）

ブラック・ショールズモデルの前提であり、連続時間における株価の基本モデル。

$$dS_t = \mu S_t \, dt + \sigma S_t \, dW_t$$

- $\mu$：ドリフト（期待リターン）
- $\sigma$：ボラティリティ（拡散係数）
- $W_t$：標準ウィーナー過程（ブラウン運動）

**Itôの公式**を適用すると対数価格の動態が得られる：

$$d \log S_t = \left(\mu - \frac{\sigma^2}{2}\right)dt + \sigma \, dW_t$$

$-\sigma^2/2$ の項は**Itô補正**と呼ばれ、確率積分特有の項。この修正により対数リターンの期待値が $\mu - \sigma^2/2$ となる（算術平均と幾何平均の差）。

**解析解**：

$$S_t = S_0 \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right]$$

つまり対数価格は正規分布に従い、価格は**対数正規分布**に従う。

| 量 | 分布 |
|---|---|
| $\log(S_t / S_0)$ | $\mathcal{N}\!\left(\left(\mu - \frac{\sigma^2}{2}\right)t,\ \sigma^2 t\right)$ |
| $S_t$ | 対数正規分布 |

## 5. 確率分布とモーメント

### 5.1 主なモーメント指標

| モーメント | 記号 | 意味 |
|---|---|---|
| 平均（1次） | $\mu$ | 分布の中心 |
| 分散（2次） | $\sigma^2$ | 散らばり具合 |
| 歪度（3次） | Skewness | 左右の偏り（負 = 左テールが重い） |
| 尖度（4次） | Kurtosis | 極端な値の出やすさ（正規分布は3） |

### 5.2 正規分布の経験則（68-95-99.7 ルール）

$$P(\mu - k\sigma \leq X \leq \mu + k\sigma) \approx \begin{cases} 68.3\% & k=1 \\ 95.5\% & k=2 \\ 99.7\% & k=3 \end{cases}$$

!!! warning "実際の金融リターン"
    実際のリターン分布はこれを超える確率（ファットテール）が観察される。正規分布を前提にしたリスク計算は過小評価になりやすい。

### 5.3 ファットテール（Fat Tail）

正規分布より極端な値が出やすい特性。代替分布として：

- **スチューデントのt分布**：自由度 $\nu$ で尾の重さを制御（$\nu \to \infty$ で正規分布に収束）
- **安定分布**：スケール則が成立する重尾分布
- **歪正規分布**：歪みとファットテールを同時に表現

超過尖度（Excess Kurtosis）= Kurtosis - 3 が正であればファットテール。

## 6. 金融時系列のスタイライズド・ファクト

実務データで繰り返し観察される普遍的な特徴（Stylized Facts）：

| ファクト | 内容 |
|---|---|
| **リターンの無相関性** | 方向の自己相関はほぼゼロ（方向予測は難しい） |
| **ボラティリティ・クラスタリング** | 絶対・二乗リターンに強い自己相関が残る。高ボラ期間が続く |
| **ファットテール** | 正規分布より極端な値が頻繁に発生する |
| **レジーム変化** | 強気・弱気・高ボラ・低ボラなど、分布の性質が時期によって変わる |
| **ボラティリティの平均回帰** | 高ボラ・低ボラは持続するが最終的に長期平均に戻る傾向がある |
| **非対称なボラティリティ** | 株価下落時にボラが上がりやすい（レバレッジ効果） |

### 6.1 自己強化フィードバックと負のスパイラル

スタイライズド・ファクトの多くは「価格が独立にランダムウォークする」前提から逸脱する。特に暴落局面では、**レバレッジ（信用・証拠金）が下落を自己増幅する**フィードバックループが働く。下落→追証→強制決済→さらに下落、という連鎖がそれにあたる。

主要な概念と名称：

| 名称 | 内容 | 出典・背景 |
|---|---|---|
| **追証スパイラル**（margin call cascade） | 信用買い残の含み損拡大→追証→投げ売り→さらに下落。信用倍率が高いほど燃料が多い | 市場マイクロストラクチャ一般 |
| **流動性スパイラル**（liquidity spiral） | **ファンディング流動性**（資金調達のしやすさ）と**市場流動性**（売買のしやすさ）が相互に悪化させ合うループ。本現象の理論的な本丸 | Brunnermeier & Pedersen (2009) |
| **ファイアセール外部性**（fire-sale externality） | 投げ売りが他の保有者の担保価値を下げ、連鎖的な売りを誘発する負の外部性 | Shleifer & Vishny (1992) |
| **再帰性**（reflexivity） | 価格と参加者の行動・信用状態が相互に作用し、均衡から自己強化的に乖離する | Soros |

これらは GBM やランダムウォークが想定しない**非線形・経路依存**のダイナミクスであり、「6. 非対称なボラティリティ（レバレッジ効果）」や「8.1 ジャンプ成分 $J_t$」の背後にある需給メカニズムでもある。

!!! note "計測について"
    オプションの **GEX**（ガンマ・エクスポージャ）がディーラーの機械的ヘッジから増幅量を一意に定量化できるのに対し、信用取引の強制決済はトリガー価格が一意に定まらず（保証金率・各社ルール・心理が絡む）、GEX に相当する標準指標は確立していない。実務では**信用倍率**と**信用評価損益率**（経験則として -20% 接近で追証多発）の組み合わせで「投げ売りの燃料」を近似的に見る。

## 7. 発展的モデル

### 7.1 ARIMA モデル

**ARMA(p, q)**：定常な時系列のトレンド・自己回帰構造を捉える。

$$X_t = c + \sum_{i=1}^p \phi_i X_{t-i} + \varepsilon_t + \sum_{j=1}^q \theta_j \varepsilon_{t-j}$$

非定常な場合は $d$ 回差分を取って ARIMA(p, d, q) に拡張する。価格への直接適用より、リターンや残差の分析に向く。

### 7.2 GARCH モデル

**ボラティリティ・クラスタリング**を捉える代表的モデル。

$$r_t = \sigma_t \varepsilon_t, \quad \varepsilon_t \overset{\text{i.i.d.}}{\sim} (0,1)$$

$$\sigma_t^2 = \omega + \alpha r_{t-1}^2 + \beta \sigma_{t-1}^2$$

- $\omega > 0,\ \alpha, \beta \geq 0$：パラメータ制約（分散の正値性）
- $\alpha$：直前のショック $r_{t-1}^2$ の影響（ARCH効果）。標準化残差 $\varepsilon_{t-1}$ ではなく実リターンの二乗を使う点に注意
- $\beta$：直前のボラティリティの持続性
- $\alpha + \beta < 1$ で（共分散）定常。$\alpha + \beta$ が 1 に近いほどボラが長く持続する。このとき無条件分散は $\omega / (1 - \alpha - \beta)$

**拡張版**：

| モデル | 特徴 |
|---|---|
| EGARCH | 非対称なボラ（レバレッジ効果）を捉える |
| GJR-GARCH | 負のショックに追加係数を付ける |
| FIGARCH | 長記憶ボラティリティを扱う |

### 7.3 Ornstein-Uhlenbeck 過程（平均回帰モデル）

スプレッド取引やペアトレードの理論的基盤。

$$dX_t = \kappa(\theta - X_t)\,dt + \sigma\,dW_t$$

- $\theta$：長期平均（均衡水準）
- $\kappa$：平均回帰速度（大きいほど早く戻る）
- $\sigma$：拡散係数

**半減期**（Half-life）：スプレッドが乖離の半分を解消するまでの期間。

$$t_{1/2} = \frac{\ln 2}{\kappa}$$

OU過程かどうかの検定として**共和分検定**（Engle-Granger、Johansen法）が使われる。

### 7.4 ジャンプ拡散モデル（Merton モデル）

GBM に不連続なジャンプ成分を追加する。

$$dS_t = \mu S_t\,dt + \sigma S_t\,dW_t + S_{t^-}(e^J - 1)\,dN_t$$

- $N_t$：強度 $\lambda$ のポアソン過程（ジャンプの到着）
- $J \sim \mathcal{N}(\mu_J, \sigma_J^2)$：ジャンプサイズの対数

GBMでは説明できない**突発的な大きな価格変動**（決算、地政学リスク等）を表現できる。

### 7.5 レジームスイッチングモデル（Hamilton モデル）

市場が複数の状態（レジーム）間を遷移するとみなす。

$$r_t \mid s_t = k \sim \mathcal{N}(\mu_k, \sigma_k^2)$$

$$P(s_t = j \mid s_{t-1} = i) = p_{ij}$$

- 強気・弱気、高ボラ・低ボラなどの状態を数式で表現
- EM アルゴリズムで遷移確率とパラメータを推定

### 7.6 隠れマルコフモデル（HMM）

7.5 のレジームスイッチングモデルは、**観測できない状態 $s_t$ がマルコフ連鎖に従う**という構造を持つ。これを一般化したものが**隠れマルコフモデル**（Hidden Markov Model）。Hamilton モデルは「正規分布を出力とする HMM」とみなせる。

構成要素：

| 要素 | 記号 | 内容 |
|---|---|---|
| 隠れ状態 | $s_t \in \{1, \ldots, K\}$ | 直接観測できないレジーム |
| 遷移確率 | $A = (a_{ij})$ | $P(s_t = j \mid s_{t-1} = i)$ |
| 出力（観測）確率 | $b_k(r_t)$ | $P(r_t \mid s_t = k)$、例：$\mathcal{N}(\mu_k, \sigma_k^2)$ |
| 初期分布 | $\pi_k$ | $P(s_1 = k)$ |

**3つの基本問題と解法アルゴリズム**：

| 問題 | 内容 | アルゴリズム |
|---|---|---|
| 評価 | 観測列の尤度 $P(r_{1:T} \mid \lambda)$ を計算 | 前向き（Forward）アルゴリズム |
| 復号 | 最尤の状態系列 $\arg\max_{s_{1:T}} P(s_{1:T} \mid r_{1:T})$ | Viterbi アルゴリズム |
| 学習 | パラメータ $\lambda = (A, B, \pi)$ を推定 | Baum-Welch（EM の特殊形） |

**金融での用途**：

- 価格リターン系列から**強気・弱気・高ボラ**などの潜在レジームを推定する
- 推定した状態に応じてポジションサイズやエクスポージャを切り替える
- VIX・出来高・金利差などを観測系列に加えた多変量 HMM でレジーム判定の精度を上げる

!!! warning "実務上の注意"
    HMM はラベルが事後的に確定する（リアルタイムでは状態がまだ揺れる）ため、**前向きフィルタ確率**で運用しないと前向きバイアスを招く。状態数 $K$ の選択は BIC/AIC や経済的解釈で行い、過剰な状態数は過学習を生む。

## 8. 価格分解とシグナル構築

### 8.1 価格変化の分解

実市場の価格変化を要素に分解すると：

$$\Delta P_t = \underbrace{\mu_t}_{\text{トレンド}} + \underbrace{\kappa(\bar{P} - P_{t-1})}_{\text{平均回帰}} + \underbrace{\varepsilon_t}_{\text{ノイズ}} + \underbrace{h(\sigma_t)}_{\text{ボラ変化}} + \underbrace{J_t}_{\text{ジャンプ}}$$

どの成分が支配的かによって有効な戦略が異なる。

### 8.2 エッジの定義

クオンツ戦略のエッジ（優位性）は**条件付き分布の有利な歪み**として定義される：

$$\text{Edge} = E\!\left[r_{t+1} \mid \text{signal}_t\right] - \text{cost} > 0$$

評価時の考慮事項：

| 項目 | 内容 |
|---|---|
| リターン分布全体 | 平均だけでなく歪度・尖度も確認する |
| リスク調整後の期待値 | シャープレシオ、カルマーレシオで評価する |
| テールリスク | ドローダウン、VaR、ES を確認する |
| 取引コスト | 手数料、スリッページ、スプレッド、ショートコスト |
| 崩壊シナリオ | エッジが消える条件（市場環境変化）を把握する |

### 8.3 シグナルの種類

| カテゴリ | 例 |
|---|---|
| モメンタム | 過去リターン、移動平均クロス、相対強度 |
| 平均回帰 | ボリンジャーバンド乖離、ペアスプレッド、残差 |
| ボラティリティ | IV-RV スプレッド、VIX レジーム、ATR 比率 |
| ファンダメンタル | PER乖離、EPSサプライズ、上方修正率 |
| 需給 | 出来高異常、建玉変化、プログラム売買 |
| マクロ | 金利差、イールドカーブ、通貨強弱 |

## 9. 情報係数（IC）とシグナル評価

**IC（Information Coefficient）**：シグナルと**翌期**実現リターンの相関係数。実務では外れ値に頑健な Spearman のランク相関を使うことが多い（Pearson 相関を使う流儀もある）。クロスセクション戦略では各時点 $t$ に銘柄横断で計算し、その時系列 $\{\text{IC}_t\}$ の平均・標準偏差を評価する。

$$\text{IC}_t = \text{RankCorr}\!\left(\text{signal}_t,\, r_{t+1}\right)$$

シグナルは時点 $t$ までの情報のみで構築し、対応させるリターンは $t+1$ 期のものを使う（同時点を対応させると前向きバイアスになる）。

| IC値 | 解釈 |
|---|---|
| 0.05 未満 | 弱い。ノイズと区別しにくい |
| 0.05 〜 0.10 | 実務で使えるレベル |
| 0.10 以上 | 強い。クロスセクション戦略では十分 |

**ICIR（IC Information Ratio）**：IC の安定性を測る。

$$\text{ICIR} = \frac{E[\text{IC}]}{\text{std}(\text{IC})}$$

ICIR > 0.5 が実用の目安。IC が高くても ICIR が低ければ再現性に疑問がある。

## 10. 戦略評価指標

### 10.1 主要指標

| 指標 | 式 | 目安 |
|---|---|---|
| **シャープレシオ** | $\frac{E[r] - r_f}{\sigma}$ | 年率 1.0 以上 |
| **カルマーレシオ** | $\frac{\text{年率リターン}}{\text{最大ドローダウン}}$ | 1.0 以上 |
| **ソルティノレシオ** | $\frac{E[r] - r_f}{\sigma_{\text{downside}}}$ | 下方リスクのみで評価 |
| **最大ドローダウン（MDD）** | $\max_t \dfrac{\text{peak}_t - V_t}{\text{peak}_t}$（$\text{peak}_t = \max_{s \leq t} V_s$、$V_t$ は資産曲線） | 戦略の生存可能性 |
| **プロフィットファクター** | $\frac{\text{総利益}}{\lvert\text{総損失}\rvert}$ | 1.5 以上が目安 |

ここで $E[r]$ はリターンの期待値、$r_f$ は無リスク金利、$\sigma$ は超過リターンの標準偏差。日次データから年率換算する場合、シャープレシオには $\sqrt{252}$ を乗じる（リターンと標準偏差を同じ頻度で揃えること）。

### 10.2 ドローダウンの構造

$$\text{DD}_t = \frac{\text{peak}_t - V_t}{\text{peak}_t}$$

ドローダウン期間が長すぎると、リバランスや撤退の判断が難しくなる。MDD だけでなく**平均回復期間**（Average Recovery Time）も確認する。

## 11. バックテストの注意点

### 11.1 主なバイアス

| バイアス | 内容 | 対策 |
|---|---|---|
| **前向きバイアス（Look-ahead Bias）** | 未来の情報を過去の意思決定に混入する | 時点整合性の厳密な管理 |
| **生存者バイアス** | 上場廃止銘柄を除外する | 上場廃止銘柄を含むユニバースを使う |
| **過剰最適化（Overfitting）** | パラメータをin-sampleに合わせすぎる | out-of-sample/ウォークフォワード検証 |
| **取引コスト無視** | 手数料・スリッページを考慮しない | 現実的なコスト仮定を組み込む |
| **市場影響コスト** | 大量注文が価格を動かす効果を無視する | 売買代金制約を設ける |
| **データスヌーピング** | 同じデータで多数の仮説を検証する | Bonferroni補正、FDR補正 |

### 11.2 ウォークフォワードテスト

in-sample でモデルを学習し、out-of-sample で評価する作業を時系列に沿ってローリングで繰り返す。

```
|--train--|--test--|
         |--train--|--test--|
                  |--train--|--test--|
```

- 各 test 期間の成績を結合して全体成績を評価する
- in-sample 期間に過学習してもtest期間で露見する

### 11.3 モンテカルロ置換検定

帰無仮説「シグナルとリターンは無関係」のもとでシャープレシオの分布を生成し、実測値の統計的有意性を確認する。並べ替えるのは**シグナル側**である点に注意：リターン系列そのものを並べ替えても平均・標準偏差は変わらないため、リターンを置換する検定は機能しない。

```python
import numpy as np

def permutation_test(signal, returns, n_sim=10000, seed=0):
    """signal[t] は時点 t のリターン returns[t] に対するポジション。
    look-ahead bias を避けるため、signal は t-1 までの情報のみで
    構築しておくこと（リターンと同時点の情報を使わない）。
    """
    rng = np.random.default_rng(seed)

    def annualized_sharpe(x):
        return x.mean() / x.std(ddof=1) * np.sqrt(252)

    observed_sharpe = annualized_sharpe(signal * returns)
    simulated = np.array([
        annualized_sharpe(rng.permutation(signal) * returns)
        for _ in range(n_sim)
    ])
    # 片側p値。+1 は実測値自身を分布に含める標準的な補正
    p_value = (np.sum(simulated >= observed_sharpe) + 1) / (n_sim + 1)
    return observed_sharpe, p_value
```

なお置換はシグナルの自己相関構造を壊すため、保有期間が長い戦略ではブロック単位の置換（block permutation）やステーショナリー・ブートストラップを検討する。

## 12. クラウディングとアルファ減衰

エッジ（8.2）は永続しない。**アノマリーは公開・周知された瞬間から劣化が始まる**。その需給上のメカニズムが**クラウディング**（crowding）であり、結果として現れる超過収益の目減りが**アルファ減衰**（alpha decay）である。

### 12.1 クラウディングとは

**同じシグナル・同じアノマリーに多数の参加者が群がり、似たポジションを保有している状態**。典型的なライフサイクルは次の通り。

1. 誰かが市場の歪み（バリュー、モメンタム、低ボラ等）を発見する
2. 論文・SNS・運用会社のマーケティングを通じて広まる
3. 同じシグナルで同じ銘柄を売買する資金が増える
4. 裁定が進み、**超過リターン（アルファ）が薄まる／消える**

McLean & Pontiff (2016) は、米国株の97アノマリーについて**論文公開後にリターンが平均で約58%減衰**したと報告している。内訳は、サンプル外で約26%の減衰（統計的バイアス＝過剰最適化の剥落に相当）、残りの約32%ポイントが公開そのもの（＝アービトラージャーの参入）に起因する。「発表された瞬間から劣化する」ことの定量的な裏付けである。

### 12.2 なぜ危険か

クラウディングが問題なのは、単にリターンが薄まるからだけではない。

| 側面 | 内容 |
|---|---|
| **アルファ減衰** | 裁定が進み超過収益が逓減する。エッジの寿命が縮む |
| **同時解消リスク**（unwind） | 危機時に「混んだトレード」が一斉に巻き戻され、価格変動が増幅される |
| **隠れた集中** | 自分では分散したつもりでも、他人と同じ持ち高であれば実質的に集中している |

3つめは特に見落とされやすい。個別銘柄では分散していても、**ファクター空間で同じ方向に賭けている**と、ストレス時に相関が1へ収束して同時に毀損する。これは「6.1 自己強化フィードバックと負のスパイラル」の流動性スパイラルと同じ構造を、ファクター・レベルで踏むことを意味する。

!!! note "クオンツ・ショック（August 2007 quant meltdown）"
    クラウディングの教科書的事例。多数のクオンツファンドが似たファクター（バリュー／モメンタム等）を保有しており、ある大手のデレバレッジが他社の含み損を誘発、追加のデレバレッジを呼ぶ連鎖で、市場全体は平穏なのに**マーケットニュートラル戦略だけが数日で大きく毀損し、その後急反発**した。Khandani & Lo (2007) は、これをファンディング流動性の収縮と過密ポジションの同時解消として説明している。

### 12.3 クラウディングの計測

クラウディングは直接観測できないため、複数の代理指標を組み合わせて推定する。

| 指標 | 内容 |
|---|---|
| **バリュエーション・スプレッド** | ファクターのロング側とショート側の割安度の差。割安側が割高化していれば過密のサイン |
| **空売り残高**（short interest） | ショートの集中度。踏み上げ（short squeeze）リスクの源 |
| **保有集中度** | 機関投資家の保有が特定銘柄・特定戦略に偏っているか（米国では13F、日本では大量保有報告等から推定） |
| **ペア間・戦略間の相関上昇** | 本来独立なはずのポジション同士の相関が高まると、同時解消リスクが増す |
| **混雑度スコア** | 上記を合成した crowding score。回転率・流動性に対するポジションの大きさ（解消に要する日数）も加味する |

### 12.4 緩和策

- エッジの**経済的根拠**（リスクプレミアムか、構造的制約か、行動バイアスか）を問い、裁定で消えやすいものを見極める
- **解消容易性**を管理する：1日の売買代金に対してポジションが大きすぎると、自分が出口で詰まる
- 公開された単一ファクターに依存せず、**相関の低いシグナルへ分散**する
- バリュエーション・スプレッドが極端なときは**エクスポージャを落とす**（混んだトレードには逆張り的に控えめに乗る）

!!! warning "バックテストとの関係"
    過去データで強いエッジほど、その期間に**すでに混んでいた**可能性がある。11章のバイアスに加え、「このシグナルは検証期間中にどれだけ知れ渡っていたか」を問うこと。広く知られたシグナルの華々しいバックテストは、これから減衰する局面を割引いていない。

## 13. 相関行列の分析：PCA と RMT

クラウディング（12章）の本質は「ファクター空間での隠れた集中」だった。それを定量化する基本ツールが、相関・共分散行列の固有値分解である。$N$ 銘柄・$T$ 期間のリターンから推定した**標本相関行列**は、$N$ が $T$ に対して大きいほどノイズに汚染される。**PCA** が構造（ファクター）を取り出し、**ランダム行列理論（RMT）** がどこまでが信号でどこからがノイズかの境界を与える。

### 13.1 主成分分析（PCA）

相関行列 $C$ を固有値分解する：

$$C = \sum_{i=1}^{N} \lambda_i\, v_i v_i^\top, \qquad \lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_N$$

- $\lambda_i$：第 $i$ 主成分が説明する分散の大きさ
- $v_i$：固有ベクトル（ファクターの方向＝各銘柄のローディング）

金融データでの典型的な構造：

| 成分 | 解釈 |
|---|---|
| **最大固有値** $\lambda_1$ | **マーケット・モード**。固有ベクトルの符号がほぼ全て同方向（市場全体の連動） |
| 上位数個 | セクター・スタイル（バリュー／グロース、大型／小型 等） |
| 残りの大多数 | 個別銘柄ノイズ。多くは RMT の範囲内に収まる |

寄与率 $\lambda_i / \sum_j \lambda_j$ で各ファクターの重要度を測る。用途は次元削減、リスク分解、そして統計的裁定の**残差（リターンからファクター成分を除いた部分）構築**。

### 13.2 ランダム行列理論（RMT）と Marchenko–Pastur 分布

「もし銘柄間が完全に無相関なら、標本相関行列の固有値はどう分布するか」を与えるのが **Marchenko–Pastur（MP）分布**。$T$ 期間・$N$ 銘柄の比を $q = N/T$ とすると、純粋ノイズの固有値は次の範囲に収まる：

$$\lambda_{\pm} = \sigma^2 \left(1 \pm \sqrt{q}\right)^2, \qquad q = \frac{N}{T}$$

相関行列では $\sigma^2 = 1$。密度関数は

$$\rho(\lambda) = \frac{1}{2\pi\, q\, \lambda}\sqrt{(\lambda_+ - \lambda)(\lambda - \lambda_-)}, \quad \lambda \in [\lambda_-, \lambda_+]$$

| 固有値の位置 | 解釈 |
|---|---|
| $\lambda > \lambda_+$ | **信号**。ノイズでは説明できない真のファクター（市場・セクター） |
| $\lambda_- \leq \lambda \leq \lambda_+$ | **ノイズの塊**（noise bulk）。無相関仮説と統計的に区別できない |

!!! note "なぜ重要か"
    $N=500$ 銘柄を $T=750$ 日（約3年）で推定すると $q \approx 0.67$、$\lambda_+ = (1+\sqrt{0.67})^2 \approx 3.3$。**固有値が約 3.3 までは純然たるノイズ**であり、ここに意味を読み取るのは過学習。実務では $N \gtrsim T$ になりがちで、相関行列の大半はノイズで埋まっている。

### 13.3 固有値クリッピングによるデノイズ

Markowitz 最適化は共分散行列の**逆行列**を要求するため、ノイズ起因の小さな固有値が暴れると最適ウェイトが不安定化する。RMT による定番の処理が**固有値クリッピング**：ノイズ塊の固有値を平均値で置き換え（トレースを保存）、信号の固有値だけ残して再構成する。

```python
import numpy as np

def rmt_clip(corr, T):
    """RMT（Marchenko-Pastur）に基づく相関行列のデノイズ"""
    N = corr.shape[0]
    q = N / T
    lambda_plus = (1 + np.sqrt(q)) ** 2          # ノイズの上限

    vals, vecs = np.linalg.eigh(corr)            # 昇順の固有値
    noise = vals <= lambda_plus
    if noise.any():                              # ノイズ塊を平均で平坦化
        vals[noise] = vals[noise].mean()

    clean = (vecs * vals) @ vecs.T               # 再構成
    d = np.sqrt(np.diag(clean))                  # 対角を1に正規化
    return clean / np.outer(d, d)
```

代替・発展手法：

| 手法 | 内容 |
|---|---|
| **Ledoit–Wolf 縮小推定** | 標本共分散と構造化ターゲット（単位行列等）を凸結合し、最適な縮小率を解析的に決める |
| **回転不変推定量（RIE）** | Ledoit–Péché。固有ベクトルを保ったまま固有値を最適変換する、RMT の発展形 |
| **階層クラスタリング** | 相関構造を木構造で捉え、ノイズに頑健なポートフォリオ（HRP）を組む |

### 13.4 クラウディングとの接続：アブソープション比率

最大固有値の寄与率（＝市場モードの強さ）が上昇するとき、銘柄間相関が一斉に高まっている＝**「全部が一緒に動く」リスクオフ／過密レジーム**を示す。これを指標化したのが **アブソープション比率**（Absorption Ratio, Kritzman et al. 2011）：

$$\text{AR} = \frac{\sum_{i=1}^{n} \lambda_i}{\sum_{j=1}^{N} \lambda_j}$$

上位 $n$ 個の固有値が全分散に占める割合（Kritzman らは $n = N/5$ 程度を使用）。**AR の急上昇が大きなドローダウンに先行する傾向**が報告されており、クラウディングの早期警戒シグナルとして使える。12.2 で述べた「隠れた集中」を、相関行列の固有値構造として観測する方法である。

## 14. 統計的裁定（Statistical Arbitrage）

### 14.1 ペアトレード

2銘柄間のスプレッドが共和分関係にある場合、スプレッドの拡大・縮小から利益を得る。

1. **共和分検定**でペアを選定する（Engle-Granger または Johansen）
2. スプレッドを OU 過程でモデル化する
3. スプレッドが乖離したら逆張りで入る（Zスコアを閾値に使う）

$$z_t = \frac{\text{spread}_t - \mu_{\text{spread}}}{\sigma_{\text{spread}}}$$

エントリー: $|z_t| > 2$、クローズ: $|z_t| < 0.5$ が典型的な例。$\mu_{\text{spread}}$・$\sigma_{\text{spread}}$ は**時点 $t$ までのデータ**（ローリング窓または拡張窓）で推定すること。全期間で推定した値を使うと前向きバイアスになる。

### 14.2 PCA ベースの統計的裁定

ペアに限らず、**PCA（13.1）でファクター成分を抽出し、各銘柄リターンをファクターに回帰した残差の平均回帰を取引する**手法（Avellaneda & Lee, 2010）。

1. リターン行列を PCA し、上位固有ベクトルを共通ファクターとする
2. 各銘柄を共通ファクターに回帰し、残差 $\epsilon_t$ を得る
3. 残差を OU 過程でモデル化し、Zスコア（s-score）で逆張りする

ペアトレードを多銘柄・多ファクターに一般化したものに相当し、共和分ペア探索の組合せ爆発を避けられる。

### 14.3 注意点

- スプレッドが崩れる（共和分関係の消失）リスクが常に存在する
- ペアを多く組み合わせる場合、相関が高い銘柄でポートフォリオが偏りやすい（13.4 のアブソープション比率で過密度を監視する）
- 半減期が長すぎると資金効率が悪い（目安は5〜30営業日）
- 残差ベースの手法は**ファクター数の選択**に敏感。RMT（13.2）で信号となる固有値の本数を決めると過学習を抑えられる
